# Math Animations

This repository contains the code used to generate mathematical animations for my teaching activities.
All animations are created with [Manim](https://www.manim.community/).

## List of Animations
1. [Sine Construction](1_sine_construction/SineConstruction.py): animates the construction of the sine function from the definition in the unit circle. [▶ Preview](media/videos/SineConstruction/1080p60/SineConstruction.mp4)
2. [Tangent Construction](2_tangent_construction/TangentConstruction.py): animates the construction of the tangent function with the same idea as animation 1. [▶ Preview](media/videos/TangentConstruction/1080p60/TangentConstruction.mp4)
3. [Cosine Construction](3_cosine_construction/CosineConstruction.py): animates the construction of the cosine function as the sine of the complementary angle. [▶ Preview](media/videos/CosineConstruction/1080p60/CosineConstruction.mp4)
4. [Kepler Laws](4_kepler_laws/KeplerLaws.py): animates Kepler's Laws on the motion of planets. [▶ Preview](media/videos/KeplerLaws/1080p60/KeplerLaws.mp4)
