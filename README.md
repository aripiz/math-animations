# Math Animations

This repository contains the code used to generate mathematical animations for my teaching activities.
All animations are created with [Manim](https://www.manim.community/).

## List of Animations
1. Sine Construction: demonstrates the construction of the sine function from the definition in the unit circle.
2. Tangent Construction: demonstrates the construction of the tangent function with the same idea as animation 1.
3. Cosine Construction: demonstrates the construction of the cosine function as the sine of the complementary angle.
4. Kepler Laws: animates Kepler's Laws on the motion of planets.
